# Personal Hub – interactive demo

Public demo of the Personal Hub interface.

**Demo URL (after enabling GitHub Pages):** https://tarlykov1.github.io/my-personal-hub-demo/

## Features
- Tasks and projects
- Calendar events
- Sample inbox with conversion of emails to tasks
- Simulated notifications and channel settings
- Browser-local storage for demo changes

No real accounts, OAuth credentials, mail, calendar or backend APIs are connected. No personal data is transmitted to the application server.

## Publish
Repository Settings → Pages → Build and deployment → Source: GitHub Actions.
Then run the **Publish demo** workflow if needed.

Private application repository: `tarlykov1/my-personal-hub`.
